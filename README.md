
# For You

This repository contains a GitHub Pages website.

## Files

- `index.html` — redirects to the main page.
- `for-u.html` — the website content.
- `publish_index_to_github.ps1` — helper script to commit and push the site.

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. In the GitHub repository settings, enable GitHub Pages from the `main` branch.
3. The site will be available at `https://<your-username>.github.io/<repository-name>/`.
